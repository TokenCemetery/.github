# ⚰️ Token Cemetery

> Where tokens go to rest. Code lives on.

Every prompt consumed, every context window exhausted, every deprecated model — they all end up here eventually.
We just make sure the *code* survives.

Open-source agents, tools, and libraries for the AI-native developer.

## What's buried here

- 🤖 **Agents** — autonomous agents that get things done
- 🧰 **Tools** — utilities, integrations, and building blocks
- 📦 **Shared libraries** — common code across all projects
- 🪦 **Experiments** — some make it out, some don't

## Philosophy

- **KISS** — small repos, single responsibility
- **Open by default** — public code, open contributions
- **Honest about failure** — not every experiment survives, and that's fine

## Contributing

Found something worth digging up? Open an issue or a PR.
We accept all contributions. Even the ones that might not make it.
